# Ожирун

**AI-дневник питания в Telegram**

Сфотографируйте тарелку или опишите еду парой слов — Ожирун посчитает калории, белки, жиры и углеводы,
сравнит с вашей дневной нормой и каждое утро пришлет разбор вчерашнего дня.

## Возможности

- **Фото или текст** — пришлите снимок тарелки, подпись к нему или `/add гречка с курицей и салат`. Никаких форм и поиска по базам продуктов.
- **Личная норма** — короткая регистрация (пол, возраст, рост, вес, активность, цель) превращается в норму калорий и макронутриентов по формуле Mifflin-St Jeor. Норму назначил тренер? Впишите ее вручную в `/settings`.
- **Последнее слово за вами** — каждый анализ приходит карточкой с кнопками «Принять», «Редактировать» и «Удалить». Пока запись не принята, она не учитывается; корректировка текстом создает новую ревизию.
- **Честные прогресс-бары** — `/stats` показывает калории и макросы за сегодня. Цвет говорит о близости к норме, а не о заполненности: 🟩 в пределах ±10%, 🟧 ±25%, 🟥 дальше. Недобор так же плох, как перебор.
- **Утренний отчет** — в 09:00 приходит таблица вчерашних приемов пищи, итог в сравнении с нормой и AI-рекомендации на сегодня. Нет записей — нет отчета.
- **Работает в группах** — ведите дневник вместе с друзьями. Статусы, подсказки и кнопки приходят эфемерными сообщениями, которые видит только автор; группе видны лишь принятая еда и карточки `/stats`.
- **Исправления задним числом** — ответьте `/yesterday`, чтобы перенести забытую еду на вчера, или `/readd`, чтобы распознать заново.
- **Только для подписчиков** — пользоваться ботом могут подписчики Telegram-канала автора.
- **Честный лимит** — до 10 записей в сутки на человека во всех чатах, чтобы расходы на AI оставались предсказуемыми.

## Как это работает

1. Отправьте `/start` в личные сообщения и ответьте на шесть вопросов — бот редактирует одну карточку по мере ответов.
2. Пришлите фото или описание еды — в ЛС или в группе.
3. Бот ответит «Принял запись» (или покажет место в очереди) и проанализирует еду vision-моделью.
4. Придет карточка: что распознано, таблица КБЖУ и прогресс калорий за день. Примите ее, поправьте текстом или удалите.
5. Утром в ЛС придет отчет за вчера.

## Команды

| Команда | Где | Что делает |
|---|---|---|
| `/start` | ЛС | регистрация и расчет дневной нормы |
| `/add` | ЛС, группа | добавить еду: с текстом или фото — сразу, без них — ждет следующее сообщение |
| `/stats` | ЛС, группа | прогресс за сегодня; в группе `/stats @username` покажет участника, который ведет дневник в этой группе |
| `/profile` | ЛС | ваши данные и норма |
| `/settings` | ЛС | вручную поменять пол, вес и норму КБЖУ |
| `/yesterday` | ЛС, группа | ответом на запись — перенести ее на вчера |
| `/readd` | ЛС, группа | ответом на сообщение с едой — распознать заново |
| `/help` | ЛС, группа | как это работает |

В личном чате основные действия вынесены на постоянную клавиатуру: «🍽 Добавить еду», «📊 Статистика», «👤 Профиль», «⚙️ Настройки», «💡 Как это работает?».

## Запуск своего экземпляра

### 1. Подготовьте Telegram

1. Создайте бота в [@BotFather](https://t.me/BotFather).
2. Отключите privacy mode (`/setprivacy` → *Disable*), чтобы в группах бот видел фото без команды.
3. Добавьте бота **администратором** в свой канал. Права на публикацию не нужны, но статус подписчиков Telegram отдает только администраторам канала.

### 2. Настройте

```bash
cp .env.example .env
```

Минимум:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_REQUIRED_CHANNEL=@your_channel
OPENROUTER_API_KEY=
```

### 3. Запустите

```bash
docker compose up --build
```

Готово: PostgreSQL поднимется рядом, миграции применятся при старте бота. Добавить бота в свою группу может любой пользователь — отдельной настройки групп нет.

## Под капотом

- **Go 1.26** и слоистая архитектура DDD / Clean Architecture, зависимости направлены внутрь.
- **Собственный клиент Telegram Bot API** — Rich Messages, эфемерных сообщений и стилей кнопок нет в готовых библиотеках.
- **Structured output OpenRouter** — ответы проверяются по JSON Schema и нормализуются до записи в БД; если модель не отвечает, клиент переключается на следующую из списка.
- **Durable-очередь задач в PostgreSQL** — анализ еды и отчеты разбирают отдельные пулы воркеров (`FOR UPDATE SKIP LOCKED` с арендой), работа переживает перезапуск и делится между несколькими инстансами.
- **Идемпотентность** — callback-действия проверяют автора и безопасно повторяются, отчет за день не уходит дважды, лимит записей держится под advisory lock.

## Разработка

```bash
docker compose -f compose.local.yml up -d   # только PostgreSQL
go run ./cmd/bot

go test -race ./...
golangci-lint run ./...
```

Отдельный прогон миграций:

```bash
DATABASE_URL="postgres://nutrition:nutrition@localhost:5432/nutrition?sslmode=disable" go run ./cmd/migrate
```

CI (GitHub Actions) запускает golangci-lint, `go mod tidy -diff`, `go vet`, тесты с `-race`, двойной прогон всех миграций на пустом PostgreSQL 17 для проверки идемпотентности и сборку Docker-образа. Dependabot раз в неделю предлагает обновления. Код пишется без комментариев — пояснения живут в этом README и в [CLAUDE.md](CLAUDE.md).

## Диагностика

- **`cannot check channel subscriptions` при старте** — бот не администратор канала, и Telegram скрывает статус подписчиков. Пока это не исправлено, проверка пропускает всех: ошибки API не блокируют пользователей.
- **Бот отвечает в ЛС, но не видит фото в группе** — не отключен privacy mode; отключите его или сделайте бота администратором группы.
- **Что-то зависло** — загляните в таблицу `jobs`. Выполненные задачи удаляются, упавшие остаются со статусом `failed`:

  ```sql
  SELECT queue, kind, status, attempts, last_error, run_at
  FROM jobs
  ORDER BY created_at DESC
  LIMIT 20;
  ```

- **Не появились подсказки команд** — Telegram обновляет меню команд с задержкой, переоткройте чат.
